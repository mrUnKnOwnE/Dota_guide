Dota 2 Hero Guide — це інтерактивний веб-ресурс (Landing Page), розроблений для допомоги гравцям у виборі персонажів відповідно до їхньої ігрової ролі. Сайт демонструє сучасні підходи до верстки та скриптингу, поєднуючи тематичний дизайн гри з високою функціональністю.

Метою проєкту було створення повністю адаптивного інтерфейсу з використанням препроцесора SCSS та чистого JavaScript.
